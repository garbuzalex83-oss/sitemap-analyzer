🎯 ВАРИАНТ А: Через командную строку (рекомендуется)

1️⃣  Откройте командную строку в папке с файлами
   (Shift + Правая кнопка → "Открыть PowerShell здесь")

2️⃣  Переименуйте README_GITHUB.md в README.md:
   Windows:
   ┌──────────────────────────────────────────────────────────────────┐
   │ ren README_GITHUB.md README.md                                   │
   └──────────────────────────────────────────────────────────────────┘
   
   Mac/Linux:
   ┌──────────────────────────────────────────────────────────────────┐
   │ mv README_GITHUB.md README.md                                    │
   └──────────────────────────────────────────────────────────────────┘

3️⃣  Инициализируйте Git репозиторий:
   ┌──────────────────────────────────────────────────────────────────┐
   │ git init                                                         │
   └──────────────────────────────────────────────────────────────────┘

4️⃣  Добавьте все файлы:
   ┌──────────────────────────────────────────────────────────────────┐
   │ git add .                                                        │
   └──────────────────────────────────────────────────────────────────┘

5️⃣  Сделайте первый commit:
   ┌──────────────────────────────────────────────────────────────────┐
   │ git commit -m "Initial commit: Sitemap Analyzer v2.0"           │
   └──────────────────────────────────────────────────────────────────┘

6️⃣  Переименуйте ветку в main (если нужно):
   ┌──────────────────────────────────────────────────────────────────┐
   │ git branch -M main                                               │
   └──────────────────────────────────────────────────────────────────┘

7️⃣  Добавьте удаленный репозиторий:
   ┌──────────────────────────────────────────────────────────────────┐
   │ git remote add origin https://github.com/YOUR-USERNAME/sitemap-analyzer.git │
   └──────────────────────────────────────────────────────────────────┘
   
   ⚠️  Замените YOUR-USERNAME на ваш username!

8️⃣  Загрузите файлы на GitHub:
   ┌──────────────────────────────────────────────────────────────────┐
   │ git push -u origin main                                          │
   └──────────────────────────────────────────────────────────────────┘

9️⃣  Введите логин и пароль GitHub (или токен)

  ❓ ЧАСТЫЕ ПРОБЛЕМЫ
═══════════════════════════════════════════════════════════════════════

🔴 "git is not recognized"
Решение: Установите Git и перезапустите командную строку

🔴 "Permission denied"
Решение: Используйте Personal Access Token вместо пароля
1. GitHub → Settings → Developer settings → Personal access tokens
2. Generate new token
3. Используйте токен вместо пароля

🔴 "remote origin already exists"
Решение:
┌─────────────────────────────────────────────────────────────────────┐
│ git remote remove origin                                            │
│ git remote add origin https://github.com/YOUR-USERNAME/repo.git     │
└─────────────────────────────────────────────────────────────────────┘

🔴 "failed to push"
Решение: Сначала скачайте изменения:
┌─────────────────────────────────────────────────────────────────────┐
│ git pull origin main --rebase                                       │
│ git push                                                            │
└─────────────────────────────────────────────────────────────────────┘
