# Contributing to Sitemap Analyzer

Спасибо за интерес к проекту! 🎉

## 🤝 Как внести вклад

### 1. Сообщить о баге

Если вы нашли баг:

1. Проверьте, не создан ли уже [Issue](https://github.com/yourusername/sitemap-analyzer/issues)
2. Создайте новый Issue с описанием:
   - Версия Python
   - Операционная система
   - Шаги для воспроизведения
   - Ожидаемое поведение
   - Фактическое поведение
   - Скриншоты (если возможно)

### 2. Предложить улучшение

Есть идея? Отлично!

1. Создайте Issue с тегом `enhancement`
2. Опишите:
   - Какую проблему решает ваша идея
   - Как это должно работать
   - Возможные альтернативы

### 3. Добавить код

#### Процесс:

1. **Fork** репозитория
2. **Clone** вашего fork
```bash
git clone https://github.com/yourusername/sitemap-analyzer.git
cd sitemap-analyzer
```

3. Создайте **ветку** для вашей фичи
```bash
git checkout -b feature/amazing-feature
```

4. Сделайте изменения
5. **Протестируйте** код
```bash
python test_demo.py
```

6. **Commit** изменений
```bash
git commit -m "Add: amazing feature description"
```

7. **Push** в вашу ветку
```bash
git push origin feature/amazing-feature
```

8. Откройте **Pull Request**

#### Стиль кода:

- Следуйте PEP 8
- Комментируйте сложные участки
- Используйте говорящие имена переменных
- Добавляйте docstrings к функциям

#### Пример:

```python
def analyze_sitemap(url: str) -> dict:
    """
    Анализирует sitemap по указанному URL
    
    Args:
        url: Полный URL sitemap файла
        
    Returns:
        dict: Словарь с результатами анализа
        
    Raises:
        ValueError: Если URL невалидный
    """
    pass
```

### 4. Улучшить документацию

Документация важна!

- Исправьте опечатки
- Добавьте примеры
- Улучшите объяснения
- Переведите на другие языки

## 📋 Checklist для Pull Request

Перед отправкой PR убедитесь:

- [ ] Код работает без ошибок
- [ ] Добавлены комментарии
- [ ] Обновлена документация (если нужно)
- [ ] Пройдены тесты
- [ ] Соблюден стиль кода
- [ ] Commit сообщения понятны
