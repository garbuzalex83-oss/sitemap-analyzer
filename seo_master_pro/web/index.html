🚀 SEO Master PRO

Профессиональный инструмент SEO-аудита уровня Enterprise

⚠️ Важно: GitHub Pages не поддерживает Python/FastAPI!

Этот инструмент требует сервер с Python для работы. Выберите способ запуска ниже:

💻 Локальный запуск

  1. Клонируйте репозиторий
  2. pip install -r requirements.txt
  3. playwright install --with-deps chromium
  4. python run_web.py
  5. Откройте http://localhost:8000

☁️ Render.com (Бесплатно)

  1. Зарегистрируйтесь на render.com
  2. Создайте Web Service
  3. Подключите GitHub репозиторий
  4. Deploy запустится автоматически
  5. Получите URL вида https://seo-master.onrender.com

🚂 Railway.app

  1. Зарегистрируйтесь на railway.app
  2. New Project → Deploy from GitHub
  3. Выберите репозиторий
  4. Railway автоматически запустит приложение
  5. Получите рабочий URL

🐳 Docker / VPS

  1. Создайте Dockerfile (инструкция в README)
  2. docker build -t seo-master-pro .
  3. docker run -p 8000:8000 seo-master-pro
  4. Или разверните на любом VPS
  5. Откройте порт 8000
